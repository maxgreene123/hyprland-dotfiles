# Keybindings

`Super` is the Windows key. These shortcuts come from `hypr/hyprland.lua`, `hypr/scripts/altswitch.lua`, and the Quickshell panels.

## Apps and panels

| Shortcut | Action |
| --- | --- |
| Super + Shift + X | Open Alacritty. |
| Super + Shift + B | Open the default browser. |
| Super + Shift + C | Open the default file manager. |
| Super + Shift + Z | Open the default text editor. |
| Super + R | Open the app launcher. |
| Super + N | Open SET quick controls and notifications. |
| Super + Comma | Open Other: hyprmoncfg, default apps, and file types. |
| Super + Shift + L | Open the dashboard, calendar, and TODO list. |
| Super + Shift + P | Select a screenshot region and edit it in Swappy. |

## Windows

| Shortcut | Action |
| --- | --- |
| Alt + Tab | Open the switcher; select the previous window. Keep holding Alt to cycle. |
| Alt + Shift + Tab | Cycle backward through the switcher. |
| Release Alt | Focus the selected window, across regular workspaces and monitors. |
| Alt + Escape | Cancel the switcher. |
| Super + Q | Close the focused window. |
| Super + V | Toggle floating. |
| Super + F | Toggle fullscreen. |
| Super + Shift + A / D | Move the window left / right. |
| Super + Shift + W / S | Move the window up / down. |
| Super + Shift + Left / Right | Shrink / grow window width by 40 pixels. |
| Super + Shift + Up / Down | Shrink / grow window height by 40 pixels. |

## Workspaces

| Shortcut | Action |
| --- | --- |
| Super + 1–9 / 0 | Focus workspace 1–9 / 10 on DP-2. |
| Super + Shift + 1–9 / 0 | Move the window to workspace 1–9 / 10. |
| Super + Alt + 1–9 / 0 | Focus workspace 11–19 / 20 on HDMI-A-1. |
| Super + Alt + Shift + 1–9 / 0 | Move the window to workspace 11–19 / 20. |

## Session and display

| Shortcut | Action |
| --- | --- |
| Super + Ctrl + Q | Lock the screen. |
| Super + Shift + E | Exit Hyprland immediately. |
| Super + Shift + N | Set warm display color: 2500 K. |
| Super + Shift + M | Restore neutral display color: 6500 K. |
| Super + Shift + J | Enable vibrance. |
| Super + Shift + K | Disable vibrance. |

## Inside Quickshell

| Shortcut | Action |
| --- | --- |
| Escape | Close the open panel. |
| Up / Down in launcher search | Select the previous / next app. |
| Enter in launcher search | Launch the selected app. |
| Enter in the TODO input | Add a task to Obsidian's TODO.md. |
| Enter in the Wi-Fi password field | Submit the password. |
| Tab / Shift + Tab | Move between focusable controls. |
| Space on a focused button | Activate the button. |

In Alacritty, Shift + Enter sends Escape followed by Return. The application running in the terminal decides what that sequence does.
